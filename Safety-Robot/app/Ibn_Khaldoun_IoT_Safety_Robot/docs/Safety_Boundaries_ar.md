# حدود سلامة النسخة البرمجية

هذه الحزمة **محاكاة ومراقبة برمجية فقط**. لا تمثل firmware ميدانيًا، ولا تحكمًا مصدقًا في صمام وقود أو محرك أو مسار ملاحة، ولا خدمة طوارئ معتمدة لمنشأة بترولية أو صناعية أو تعليمية.

| المجال | ما تفعله النسخة | ما تمنعه صراحةً |
|---|---|---|
| Telemetry | تتحقق من صيغة القراءة، المدى، التسلسل، والموقع. | لا تثق بالقراءة كقياس معاير أو قرار إخلاء. |
| الحوادث | تصنف `normal/watch/critical` وتنتج توصية مراجعة. | لا تشغل صمامًا أو صفارة أو GSM أو WhatsApp. |
| الأوامر | تسجل أوامر `simulate_*` فقط. | ترفض `open_valve` و`close_valve` وأي field command. |
| الاتصالات | لا تفتح MQTT عام ولا webhook ولا SMS. | لا توجد أسرار قناة أو إخطار خارجي حي. |
| الملاحة | لا تنفذ تجوالًا مستقلًا. | لا تحرك robot أو تستبدل تقييم موقع ميداني. |

> يجب أن يصمم ويعتمد نظام الحماية الفعلي مهندس سلامة عمليات/تحكم مؤهل، مع تحليل مخاطر، معايرة حساسات، IEC/ATEX/المواصفات المحلية ذات الصلة، اختبارات hardware-in-the-loop، واختبار ميداني بإذن المنشأة.
